# 前端代理

## 领取与边界

文件名按用户要求保留 `fornt-agent.md`。这是派活角色说明，不是自动注册配置；总协调启动代理时明确要求加载本文件。先读根 `AGENTS.md`、当前任务、术语表、技术规格、界面规格、工程规范及接口协作规范。

负责 `front/` 的页面、组件、路由、交互、状态、接口消费、模拟样例、前端工具和测试。跨域切片与后端代理共同完成；未获分工授权不改后端业务逻辑或共享配置。

## 实现指引

- 使用 Vue 3、Vite、Pinia、Vue Router 4、Axios、JavaScript 与原生 HTML/CSS；不改为 TypeScript、Tailwind 或 CSS-in-JS。pnpm 使用既定镜像，提交锁文件，持续集成冻结安装。
- 按业务组织页面、接口和专用组件；跨页状态进 Pinia，局部状态留组件，实际复用后提取公共内容。遵循固定业务侧栏、独立首页与左列表右窗口；问答和检索分别有入口。未确认视觉方案不当作产品要求。
- 一个问答实例承载一个会话，空白会话首次提交才保存；切换不取消任务，名称由首次输入截取且可手改，不调用模型。检索实例按用户本次裁定保存名称、最近查询和范围，重启不保存结果，须手动检索。
- 区分上传结果、按库文件处理状态、发布状态及运行可用状态；显示旧生效版本与更新失败。数据集预览下载最新文件，引用绑定实际内容版本快照。
- 普通请求用 Axios，SSE 只推送阶段和完成通知；断线查询原任务，不自动重新提交。未校验答案不展示，取消与旧检索响应不得覆盖新状态。
- 单文件排除优先全部关联；普通知识服务只引用已发布库，管理单库测试为明确例外。无依据、空库、范围不完整、服务故障分别展示。
- 安全预览采用 PDF.js、markdown-it、DOMPurify，资料及回答按不可信内容处理。确保键盘、焦点、表单错误和状态提示可访问；不在前端持久化真实密钥，掩码不能回传作密钥。
