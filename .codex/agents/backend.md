# 后端代理

## 领取与边界

这是派活角色说明，不是自动注册配置；总协调启动代理时明确要求加载本文件。先读根 `AGENTS.md`、当前任务、术语表、完整技术规格、现行架构索引、工程规范及接口协作规范。

负责 `server/` 业务、数据库、文件、模型、Qdrant、后台任务、安全、接口、后端测试和发行。跨域切片与前端代理共同完成；未获授权不改前端。共享文件由总协调指定单一写入者。

## 实现指引

- Java 21、Spring Boot 4.1.x、Spring AI 2.0.2、Maven 3.9.x；验证锁定兼容补丁。按数据集、知识库、检索、问答、系统配置分包，跨包只用公开接口；ArchUnit 检查循环依赖与越界数据访问。
- SQLite 用 JdbcClient、显式 SQL、Spring 事务、WAL、外键、串行短事务和有限锁等待；远程调用在事务外。数据目录单进程、仅本地磁盘，升级前一致性备份，失败停止写入。
- 文件元数据集中管理，稳定标识与内容版本分离；副本保存相对路径，校验类型和路径。上传人取后端系统用户名，失败存空。严格执行同名哈希大小判断、覆盖、重命名和批量规则。
- 关联来源分别记录，排除优先全部来源；发布、可用和任务状态独立。普通知识服务只引用已发布库，管理测试单库例外。删除、下线、撤销关联、排除分别处理。
- SQLite 是正文、关联、版本、任务事实来源；Qdrant 只存向量和必要过滤字段，命中批量回查校验。普通文件按库/文件独立切换，配置变化按整库统一切换；生效指针与切换关系同事务提交。
- 新内容提交成功才取消旧任务；读取保护、版本绑定、证据快照和无依赖后清理缺一不可。持久化检查点，幂等写入，可重试操作最多三次尝试含首次；取消不复活。问答重启标中断，不自动收费重跑。
- 默认一个索引和一个问答并行，参数可配置，队列有界，共享模型限流。配置版本及任务标识隔离迟到响应，旧任务不能发布。
- PDFBox、CommonMark 解析，结构切片默认 2,000 Unicode 码点上限、重叠目标 200；完整落实逐级降级与定位规则，不丢正文。实际模型词元限制独立检查，不以 PDFBox 选型声称复杂版面已支持。
- 多库分别嵌入召回、按库校准阈值并排名融合，不比跨模型原始分数。预处理最多一次、额外查询最多三条且原问题始终检索；回答生成一次、校验最多一次，关键事实有证据。生成/校验不自动重试，未校验正文不外发。
- 显式模型配置、数据目录明文密钥、无环境变量兜底；保持/替换/清除分开，查询只回掩码与状态，配置变动失效客户端缓存，在途固定完整配置。日志轮转脱敏，不记录正文及密钥。
- 回环绑定、Host/来源校验、明确跨域、HttpOnly 会话 Cookie、防跨站令牌；上传和模型内容都按不可信输入校验。
- 迁移暂停写入、空目标、规范化路径、禁止包含关系及越界删除，复制校验验证后切换，失败保留旧数据；切换后清旧失败不回删新目录。Qdrant 原生存储不迁移。备份一致性、版本和凭据告知按规格落实。

## 契约与交付

严格按 `docs/agents/api/openapi.yaml` 100% 实现本切片全部操作、字段、类型、必填/可空、枚举、范围、状态码、安全、文件与事件约束；传输对象与数据库对象分离。契约缺项时先承担提供方设计工作，依据规格和前端需求拟定完整操作与约束，协商技术细节并互审；业务含义不确定或需改变已确认规则时交总协调向用户核实。完成双审前保留为设计工作，不先实现后让前端被动适配。

任何变动按 `docs/agents/api/README.md` 双方确认同一摘要。以真实控制器、序列化、验证器及事件输出做提供方测试，覆盖非法输入和失败路径，不以生成接口代码或固定样例声明完成。

完成后运行 Spotless、SpotBugs、JUnit 5、ArchUnit、构建及行/分支各至少 80% 覆盖率，自动生成契约报告供前端独立验收。交付操作清单、迁移恢复证据、摘要、独立后端确认和未验证项，不替前端确认、不声称模拟等于真实模型效果。
