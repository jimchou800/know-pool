# 现行技术架构索引

## 依据与状态

替代早期架构草案，完整行为以 `spec.md` 最新确认项为准。工程、接口实现、兼容性和真实效果尚未验收。最新确认覆盖明确被替代的历史建议。

## 工程与领域

根 Maven 管理公共版本及工具版本门禁，聚合 `front/`、`server/`、`verification/`；前后端各自检查与构建，验证模块在两方产物就绪后执行统一联调和契约报告。本地模块化单体按数据集、知识库、检索、问答、系统配置分包，跨业务使用公开接口。Java 21、Spring Boot 4.1.x、Spring AI 2.0.2、Maven 3.9.x、JdbcClient 和显式 SQL；精确补丁及迁移工具仍待验证。

前端 Vue 3、Vite、Pinia、Vue Router 4、Axios、JavaScript 与原生 CSS，pnpm 指定镜像及冻结锁文件。开发 Vite 代理，发行 Spring Boot 同源提供静态资源与接口；Windows x64、主流 Chrome/Edge，压缩包包含 Java 运行时。

数据集负责原文件生命周期，知识库负责关联、排除、配置、索引和发布；问答复用检索。知识服务左侧按类型列实例，右侧呈现当前实例；问答保存会话，检索保存名称、最近查询和范围，重启手动检索，不保留结果。

## 数据与版本

SQLite 保存文件元数据、正文、位置、关联、排除、版本、任务及证据快照；使用 WAL、外键、串行短事务、有限锁等待和单目录单进程，本地磁盘。原格式文件副本按稳定标识保存相对路径，元数据集中管理。Qdrant 独立部署，每知识库独立生效集合，仅存向量和必要过滤标识，命中后批量回查 SQLite。

同数据集完整文件名不区分大小写；同名哈希及大小相同跳过，否则保留文件标识新增内容版本，不同名同内容独立保存。上传成功后向已关联库自动排队，新版本提交后取消旧任务。来源并集，排除优先全部来源。

普通内容按库和文件切换，配置变化按整库统一构建验证后切换；旧索引继续服务，失败保留。生效指针及前后内容、处理、配置版本与任务关系同 SQLite 事务记录。发布前校验取消、有效范围和当前目标版本。旧副本等待生效索引、任务和读取释放且快照已保存后清理。

## 解析与检索问答

PDFBox、CommonMark 解析，PDF.js、markdown-it、DOMPurify 预览。仅文字 PDF、Markdown、纯文本，结构切片默认硬上限 2,000 Unicode 码点、目标重叠 200；句子、表格、代码逐级降级，不丢正文，保留位置及续片。实际模型词元限制独立校验，复杂 PDF 恢复仍需测量。

按库嵌入、召回、阈值校准，数量有界，去重排名融合，不比较跨模型原始分数。最多一次预处理、三条额外查询，原问题始终检索；严格基于证据回答，生成一次、模型校验最多一次，校验前不外发正文。无依据、部分缺口、矛盾资料和服务故障分别表达。

问答返回持久化任务标识，SSE 通知阶段和完成，断线查询原任务不重跑。问答重启标中断，索引从持久化检查点恢复。每可重试索引操作最多三次尝试含首次，取消不复活；队列有界、共享限流，默认一个索引与一个问答并行。单会话一个未结束任务，单检索实例最新提交取消旧请求。

## 发布和清理

未发布、已发布、已下线独立于运行可用状态和任务状态。至少一份有效已索引文件才能发布，资料归零自动下线，恢复资料不自动发布。管理单库测试为例外。下线阻止新请求，已有问答可完成，不取消索引任务。配置重建不改变发布状态。

删除数据集级联资料不删除知识库，删除知识库不删除源文件；立即逻辑下线，后台幂等清理自有资源。历史引用保存实际完整切片、引用时名称、版本及位置，不复制整文件，随会话删除清理。

## 安全、配置与恢复

回环绑定、Host/来源检查、明确开发跨域、HttpOnly Cookie 和防跨站令牌；输入、路径和预览均需验证。首批 DashScope，生成模型 `qwen3.8-max` 待核实，嵌入 `text-embedding-v4`、1024 维为基线，各库配置独立。显式配置，明文密钥位于数据目录，无环境变量兜底；掩码读取，保持/替换/清除分开，缓存失效及在途完整配置快照。

迁移暂停写入、只接受空或不存在本地目标，禁止源目标包含、根目录/源码误删及链接扩散；复制校验和新路径验证后切换，失败保护旧数据，清旧失败不回删新目录。Qdrant 原生存储不迁移。备份 SQLite 一致性数据、文件、配置和版本，不含 Qdrant 快照；恢复核查并按需重建，告知费用和明文凭据。
