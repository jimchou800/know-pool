## 定位共同技术语义

以下已与 `/root/backend09` 技术协商一致，等待协调正式契约摘要双审：

- Markdown 与纯文本源行从 1 开始，起止均包含。只移除开头一个 BOM，CRLF 与孤立 CR 统一为 LF，保留末尾空行；与现有 `sourceLines` 相同。屏幕折行不是源行。原文件哈希与下载仍用原始字节。
- `titlePath` 由外到内包含当前所属标题；标题块自身包含自身标题。重复同名标题允许，路径不能替代结构身份。跨结构聚合片取所有正文来源共有的标题祖先路径，没有则为空数组。
- `paragraphId` 绑定真实段落或单个列表项；同段拆分共享身份，跨独立段落聚合片为 `null`，不把片段全局序号称作段落标识。`structureId` 绑定实际容器结构；同一列表容器内可共享，跨无共同容器的聚合片为 `null`。身份由后端按实际内容版本、结构类型和来源范围生成，前端不解析或重建其算法。
- 同结构续片共享结构身份，`continuationIndex` 从 0 开始；不适用时为 `null`，不能用每文件切片序号伪装结构续片。界面可显示“第 1 片”等人类序号，但保留原始索引供追溯。
- 表格行和列从 0 开始，表头为第 0 行，范围两端包含。Markdown 分隔行计入源行范围，但不是数据行；重复注入表头不扩大该片实际数据行范围。表格拆片保留同一结构身份，不称作完整独立表格；界面展示人类序号时加 1，并明确包含表头。未知行列显示未提供而非 0。
- PDF 至少提供实际起止页，从 1 开始且两端包含；不伪造 Markdown 源行或表格坐标。无法可靠建立的标题、段落及结构字段为 `null` 或空路径。跨页片显示完整范围并从起始页打开，可用已有页码导航核对后续页，不承诺矩形或逐字高亮。
- 所有定位字段仍必须存在，不适用明确为 `null`；前端不得以缺字段默认值补成有效证据。非法范围拒绝消费，不自动夹到第一页或第一行冒充定位成功。

界面直接显示 `Evidence` 返回的引用时名称、实际版本和完整正文，以转义文本呈现标题、身份、代码语言及片段。标题路径、段落身份、结构身份和续片仅在有值时展示；代码保留块身份和语言。结果列表至少显示页/行范围与标题路径，完整依据区域显示其余定位信息。保留原文不可用、仍用旧生效版本和更新失败提示。

## 版本原文的最小闭环

### 保持指定版本操作全部在 12 的可行方案

先 `getFile` 保存版本元数据，仅当 `latestVersion.id` 等于证据 `contentVersionId` 且副本可用，才请求 `previewLatestFile`；收完原始完整字节后再 `getFile`，要求两次最新版本、文件、哈希、大小、类型和媒体一致并与证据版本相等，本地用 SHA-256 核验字节及字节数。全部完成前不解码、不挂载预览、不标记成功。再检查当前预览请求身份，才显示已固定的旧字节；之后发生覆盖不改变这批已验证字节。

任一步出现覆盖、删除、错误、不匹配或哈希能力不可用，只保留完整证据和原版本坐标，提示该版本原文暂不可打开，不退回最新正文，不自动重试或重新检索。旧证据在当前版本不同的情况下无法打开完整原文，必须如实提示；证据快照仍可核对。此方案能拒绝错版，但需要两次元数据读取、一次完整字节读取和一次本地哈希；失败与竞争分支比指定版本路由更多。

### 推荐：09 仅提前 `previewVersionFile`

直接请求正式已有的 `/files/{fileId}/versions/{contentVersionId}/preview`，两个路径标识来自已验证的完整证据。此路由在后端取得指定版本读取保护，读取目标版本元信息与原始字节，不拿当前 `latestVersion` 的媒体或大小解释旧版本。前端校验响应媒体与 `location.format` 对应，不根据当前名称或最新版本猜类型。

这比最新接口双核更少代码和失败分支，也允许仍被生效索引保护的旧版本打开。与后端及协调已形成此项技术建议；只有协调完成 09/12 操作映射、累积分母及必要契约双审后才作为实施范围。`downloadVersionFile`、完整版本切换历史与 12 其他验收继续留 12；12 复用并回归 09 的指定版本预览，不将整票视作提前完成。

完整原文不可用时不发预览请求；读取期间被清理返回 410 时保留证据并提示完整原文已不可用；404 显示资料或版本不存在，500 显示读取失败而非误称清理；请求失败允许显式重试原预览，绝不重跑索引或检索。具体错误码和状态按正式契约，不新增私有错误协议。版本预览区不提供最新下载按钮，也不把证据片段保存为完整旧文件。

## 初始定位、焦点与异步安全

`TextPreview` 增加可选初始源行，普通数据集调用不传则保持现状。证据调用初次挂载后验证行存在，打开源文本并定位到起始行；范围可在外围文字提示，必要时同时标识范围内源行，不从净化后的 HTML 反推坐标。长行可滚动，不撑开全页。

`PdfPreview` 增加可选初始页，在文档加载得到总页数后校验并渲染起始页，不能先显示第一页冒充定位。超页界限明确提示；保留 PDF.js 禁脚本、链接、表单、附件、现有本地资源及单页画布、文字量与时限保护。范围提示在预览外持续可见。PDF 原文不能仅凭正文同名标题定位。

预览使用局部序号，捕获请求、证据、文件与内容版本身份。关闭预览、关闭依据、新检索、切换依据、结果失效和卸载均递增序号、清空正文并释放渲染资源；每个网络、动态导入、解码、下一次界面更新与渲染后的写入都先检查身份。`finally` 也不得重置后来请求的加载状态。PDF 沿用现有渲染取消和卸载清理。新预览按身份设置键重新挂载，避免仅替换 `bytes` 时继续展示旧文档。

依据进入时焦点落到可聚焦标题或关闭按钮；原文预览进入先聚焦预览标题/状态，成功文本定位后可聚焦实际源行，PDF 保留可用导航焦点。关闭原文返回“打开对应版本原文”触发按钮；关闭依据返回命中项按钮。Escape 按当前最内层关闭，避免一次关闭两层；异步焦点操作检查当前序号与节点仍连接，不能在用户已切换后夺焦点。加载、失败、定位错误用状态或警报文本，键盘焦点可见。

预览复用文本的 800,000 字节、20 万字符和 1 万行限制及严格 UTF-8、空字符检查，PDF 复用现有限制。这些是预览保护，不能冒充全文索引上限；预览受限仍保留完整切片与实际位置，明确当前无法完整预览。指定版本下载未交付时不提示一个不存在的下载能力。资料、标题和证据不执行外链或危险标记，不新增前端持久化正文。

## 固定资料与验证计划

| 固定资料或竞争场景 | 必需观察 |
| --- | --- |
| 中文 Markdown：嵌套及重复标题、标题前正文、两个独立段落、列表、管道表格、代码、补充平面字符、BOM/混合换行/末尾空行 | 真实上传与索引后命中；标题路径和真实段落身份、续片归属、表格行列、源行起止一致；原始字节不变 |
| 中文双页及新增跨页句子、跨页表格样例 | 真实证据完整内容及起止页；预览从起始页开始且可导航到末页，不把页界强拆成句末；无可靠表格坐标时不编造 |
| 损坏、后页资源异常、阅读顺序无法可靠恢复、图片扫描样例 | 真实后端拒绝或任务失败及限制提示；失败没有部分成功索引，不声称扫描识别或复杂版面全面支持 |
| 指定旧版本仍保留，最新被覆盖或更换文件类型 | 固定请求始终取证据版本；媒体按实际旧版本；没有最新请求退路 |
| 清理、删除、404/410/500、预览超时或超限 | 保留可用证据，明确错误及恢复入口，不静默显示第一行/页或新版本，不重新调用模型 |
| 请求 A 迟到、B 已打开，关闭后迟到，切换知识库、结果失效 | 正文、状态、焦点均不被 A 改写；PDF 任务与资源已释放 |

组件及客户端测试观察实际路径、标识、请求头和可见行为，补充非法定位与媒体/头部反例；既有普通预览保持原行为。前端新增分支先按任务后续约定执行测试驱动，不在设计阶段编写业务代码。

浏览器沿用真实应用与本机嵌入、向量替身，完成创建数据集、上传两格式、关联知识库、索引、单库管理检索、读取完整证据和打开版本原文。三宽为 1280、1440、1920；检查长名称、标题路径、结构身份与源文本换行/滚动，键盘定位、关闭与焦点返回，截图留存。使用与后端同一份固定资料及预期页/行清单，不用前端手写命中冒充真实映射。

实施后执行前端全部格式、静态、组件测试、生产构建和行/分支各至少 80% 门禁，由协调运行同快照根 `mvn verify`，自动生成契约报告并由两领域独立审阅。普通验证不使用真实收费模型。当前仅阅读与设计，未运行 09 测试、浏览器、全文性能测量或契约报告，不宣称实现或验收完成。
