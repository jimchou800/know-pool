## 每个切片的共同验收条件

- 从可操作界面贯穿契约、业务、持久化及测试，具有独立可演示结果；外部模型和故障用固定替身，普通验收不依赖真实收费调用。
- 明确前端与后端工作包，由对应角色实施；接口先定义并按唯一契约双向确认，范围内操作、字段、类型和约束 100% 实现，自动报告与两方独立确认齐全。未来未完成范围单列，不能伪称全项目 100%。
- 接通统一检查、相关有效测试、前后端行和分支覆盖率门槛；包括错误和边界场景、原有切片回归及端到端证据。首次切片建立门禁，此后每片继续执行。
- 更新操作清单、契约、样例、说明及验收记录；普通任务完成须证据验收，不能以任一领域完成代替整体完成。

以下阻塞仅列硬前置，继承其传递依赖；未阻塞的分支可按协作规则并行推进。每片只实现所述窄路径，后续功能不提前塞入。

## 拟发布任务

1. **建立本机启动与接口契约验证闭环**
   - 阻塞：无。
   - 交付：从启动应用进入中文首页，初始化本机会话并显示基础运行状态，前后端同源链路可验证。
   - 验收：固定兼容工具链与根验证，接入安全来源及请求保护、自动契约 JSON/中文报告；错误字段/缺约束/空契约/任一方未确认能阻断验收。包含前后端真实测试和一个最小接口的完整双向证据，不能只搭空工程。
2. **创建、查看和重命名数据集**
   - 阻塞：01。
   - 交付：数据集列表、创建、详情、修改名称与说明，以及无资料空态。
   - 验收：稳定标识、名称去首尾空白并按同类不区分大小写唯一，空名及并发冲突正确拒绝；重启后记录存在。
3. **上传与读取单份纯文本资料**
   - 阻塞：02。
   - 交付：上传一份纯文本，查看集中元数据、最新文本预览及原格式下载。
   - 验收：副本相对路径和文件类型/大小校验、稳定标识及内容版本、系统上传人或空值兜底；路径穿越、失败写入不损坏原数据。
4. **预览与下载 Markdown 和文字 PDF**
   - 阻塞：03。
   - 交付：三种首版文件均可安全上传、按原格式预览与下载，支持页码/文本定位基础。
   - 验收：危险内容清洗、下载响应头、错误/损坏文件和扫描 PDF 不支持提示；预览文本不替代原始副本。
5. **完成批量上传、同名覆盖与重命名规则**
   - 阻塞：03。
   - 交付：同名未变跳过、变化生成新版本，不同名同内容独立保存；重命名冲突拒绝，批量逐项反馈和重试。
   - 验收：批内重名组先选一个、其余继续，覆盖失败保留原版本；并发校验一致，元数据与版本可追溯，无索引时不伪造索引切换。
6. **配置生成与嵌入模型并测试连接**
   - 阻塞：01。
   - 交付：设置页分别编辑两类模型，读取掩码状态，选择保持/替换/清除密钥并查看连接测试结果。
   - 验收：明文只在后端数据目录，无环境变量兜底；客户端缓存和在途配置一致，错误与日志脱敏。自动测试用替身，真实调用须单独授权，指定生成模型未核实不得擅自替换。
7. **创建空知识库并关联一份资料**
   - 阻塞：03、06。
   - 交付：创建独立配置知识库，查看未发布状态、文件关联与待处理信息；可保存空库。
   - 验收：同类名称唯一，专属集合与业务记录协调创建和补偿；未完成初始化不可用，失败补偿不删他库资源。
8. **处理一份纯文本并执行管理检索测试**
   - 阻塞：07。
   - 交付：关联纯文本后自动排队，解析、切片、嵌入、写向量，管理页展示进度并返回可定位的单库检索结果。
   - 验收：有界队列、持久化阶段及幂等标识、码点硬上限、正文与位置完整；从首次存在索引起就校验目标内容和配置版本及关联有效性，阻止过时结果发布，不能推迟到任务 12。管理测试仅当前生效单库，无索引提示，未发布库仍不进入普通服务。
9. **索引 Markdown 与文字 PDF 并验证原文定位**
   - 阻塞：04、08。
   - 交付：两种文件的索引状态、管理检索结果和对应原文定位可演示。
   - 验收：标题、段落、页码及跨页位置固定样例；损坏或阅读顺序异常报告真实限制，不将页面换行当语义边界，不声称扫描识别支持。
10. **配置结构切片、降级拆分与预检**
    - 阻塞：09。
    - 交付：知识库选择结构优先、固定长度或 PDF 按页策略，调整重叠并查看切片样例、长度分布、降级与空文本报告。
    - 验收：句子、表格、代码逐级降级、重复文字占预算、Unicode 不截断代理对、内容无丢失及续片定位；超模型输入限制明确失败，资源超限不静默截断。自定义元信息不能覆盖系统字段。
11. **同步数据集并管理多来源及文件排除**
    - 阻塞：08。
    - 交付：知识库关联数据集自动处理新增资料，混用单文件关联，展示来源；排除和取消排除可操作。
    - 验收：任一来源保留但排除优先，撤销最后来源立即下线，取消排除仅依据仍有效来源；重复来源不建重复索引，迟到任务不能重新纳入。
12. **更新资料、取消旧任务并追溯版本切换**
    - 阻塞：05、08。
    - 交付：上传修订版后各库独立处理和切换，界面区分当前上传内容与生效索引，展示前后切换关系。
    - 验收：新版本提交成功才取消旧任务，迟到结果不发布；指针和切换记录同事务、失败保留旧索引，更新竞争和在途读取一致。
13. **发布、下线和重新发布知识库**
    - 阻塞：11。
    - 交付：三个发布状态可操作；有效已索引资料门槛及无资料自动下线在界面与后端一致。
    - 验收：空库、全部排除、全未索引拒绝发布，恢复资料不自动发布；主动下线保留处理与索引，普通服务不能绕过，临时服务故障只改可用状态。
14. **在知识服务执行多知识库检索**
    - 阻塞：13。
    - 交付：选择已发布库、提交查询，按原文切片展示来源版本与位置，无结果和服务故障分别提示。
    - 验收：按库嵌入、阈值及配额、去重排名融合、生效版本回查；部分库失败明确范围不完整，全失败终止，不显示跨模型统一可信度。
15. **创建和切换检索实例**
    - 阻塞：14。
    - 交付：独立检索入口左列表右窗口，新建命名重命名切换、删除确认，最新提交取消旧检索。
    - 验收：运行期切换保留结果；重启仅恢复名称、最近查询和范围，手动重新检索；旧响应、删除后响应不复活实例，跨实例不互相取消。
16. **异步问答并展示校验后的引用回答**
    - 阻塞：14。
    - 交付：问答实例首问返回任务标识、SSE 阶段进度，引用校验通过后展示最终回答与内容版本切片快照。
    - 验收：原问题及最多三条额外查询、生成和校验预算限制、无依据不生成、部分问题缺证据和矛盾资料处理；校验失败不展示草稿，引用快照不复制整份文件，提示注入不改变范围。
17. **保存多轮会话并处理取消、断线和删除**
    - 阻塞：16。
    - 交付：历史会话列表、首问命名手改、多轮追问、逐轮范围调整、进度恢复、取消与实例删除。
    - 验收：空白首问前不保存，同会话一个未结束任务；近期完整轮次预算无摘要，断线查询不重跑，重启标中断；历史只辅助理解不替代证据，删除清理专属快照且迟到结果不复活。
18. **配置变更后整库重建并原子切换**
    - 阻塞：10、12。
    - 交付：修改切片/嵌入配置后后台构建新集合，验证成功整库切换并记录关系，失败旧库继续服务。
    - 验收：不混用不兼容向量，新旧配置与版本完整追溯；仅换密钥不重建，接口变更验证兼容；保持当前发布状态，主动下线不因完成重建而重新发布。
19. **恢复索引任务并重试失败项**
    - 阻塞：12。
    - 交付：索引重启从安全检查点恢复，单文件及全失败项重试入口可用，展示失败原因和任务历史。
    - 验收：每可重试操作最多三次含首次，非重试错误直接停；取消/过时任务不复活，有任务不重复创建，成功项不重做；单库故障可重新检查恢复，不持续轮询。
20. **删除传播及安全清理废弃数据**
    - 阻塞：11、12、13、17。
    - 交付：删除文件、数据集和知识库前展示准确影响，执行后新请求立即不可用，后台清理可追踪并重试。
    - 验收：数据集删资料不删库，删库不删源资料；只清自有资源；读取释放且引用快照已保存才清旧副本，版本切换关系保留，历史快照仍可查看，无资料触发自动下线。
21. **迁移数据目录并处理中断恢复**
    - 阻塞：17、19、20。
    - 交付：设置页选择新目录，暂停写入、复制校验、验证切换及清旧，展示过程和可恢复错误。
    - 验收：只接受空/不存在本地目标，路径包含/根目录/源码/链接边界安全；复制、验证、配置保存和清旧失败分别覆盖；Qdrant 不迁移原生存储，无法验证不宣称全部恢复。
22. **备份和恢复完整应用数据**
    - 阻塞：18、19、20。
    - 交付：用户发起一致性备份和恢复，恢复后能查看资料、历史并检查或重建知识库索引。
    - 验收：暂停变更，SQLite 一致性而非仅复制主文件，文件配置版本完整校验，备份不递归含自身；明文凭据告知，不含 Qdrant 快照，缺索引提示重建费用，模拟故障验证恢复。
23. **评估中文检索问答质量与资源边界**
    - 阻塞：09、10、14、16、17、18、19。
    - 交付：固定中文资料与问题集可重跑评测报告，配置经测量的上传/解析/查询资源限额和预算。
    - 验收：覆盖精确术语、同义、跨页、表格、多资料、无答案、矛盾及错误范围，分开记录召回/排序/覆盖/准确/忠实/引用/延迟/费用；普通模拟与真实模型效果分开，真实评测单独授权，不默认增加混合检索或重排。
24. **验证 Windows 发行包和完整契约交付**
    - 阻塞：15、17、18、19、20、21、22、23。
    - 交付：包含 Java 运行时的发行包在目标环境启动，主流程可操作，输出完整接口契约验收报告和双方确认。
    - 验收：Chrome/Edge、同源安全、Qdrant 独立依赖、单目录单进程、升级前备份与失败停写；不含个人资料和凭据，所有正式操作与字段约束 100% 对齐且无未验证项，根验证及发行回归通过。
