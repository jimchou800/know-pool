## 当前访谈轮次

继续技术架构访谈，仅更新现有文档，不另建规格。暂停的规格发布流程不继续执行。

上轮已确认并调整的架构选择：

1. 最新决定替代此前统一嵌入配置：每个知识库独立配置切片规则、嵌入模型、维度和相似度度量，创建时创建专属集合。变更后重建验证再切换，生成模型更换不因此重建嵌入索引。
2. 检索先实现向量检索与知识库范围过滤，用固定中文资料与问题集验证；混合检索、重排是否进入首版以评估结果决定。新增要求：设计问题改写、拆分等处理，关注准确性、召回率和回答忠实度。
3. 解析与预览采用后端 PDFBox、CommonMark，前端 PDF.js、markdown-it 与 DOMPurify；用于索引的解析文本不替代原格式文件。具体版本与兼容性尚需验证。

切片策略与元信息分层已确认。系统长度硬上限默认 2,000 个 Unicode 码点，可配置。优先完整结构，再按完整句子组合；单句超限依次按分隔符与最大长度拆分。表格依次按行、单元格与最大长度拆，不因长度超限失败，保留来源与续片关系。实际模型输入上限仍在调用前独立校验。重叠默认目标 200 字符；代码按行优先、最大长度兜底。

已确认问题预处理方案：最多一次调用，保留原问题检索，最多三条额外查询，不递归拆分；同义扩展与互补子问题分开处理；各路限定知识库及生效索引，去重后采用倒数排名融合，预处理异常退回原问题。候选数量、超时和词元预算待评测确定。

回答方案已确认：严格基于证据，关键事实有引用，缺少依据只回答有证据部分，矛盾资料展示差异与来源；先生成完整草稿，确定性引用校验与最多一次模型校验通过后再展示正文，期间可推送进度。未通过不递归修订，不将未校验正文展示为最终答案。

上下文与数据职责已确认：按实际模型预算组装证据，优先兼顾子问题覆盖；SQLite 保存切片正文、来源、关联、版本及任务状态，Qdrant 保存向量与必要过滤字段；命中后批量回查 SQLite 验证范围和版本。可从文件与切片重建索引，但可能需重新调用嵌入服务。

索引发布与恢复已确认：新版本构建验证后切换，失败保留旧版本；普通索引按知识库与文件独立发布，整体配置变更按受影响范围统一切换；阶段与批次持久化后恢复，后台可重试操作最多三次尝试含首次，使用退避与幂等写入。废弃数据后台清理，在途读取保护与保留时间待定。

SQLite 运行约束已确认：驱动与运行库随软件打包并锁定，不建设多 SQLite 引擎版本兼容；单数据目录单进程、本地磁盘、WAL 与外键约束、应用串行写入和短事务、有限锁等待。应用表结构记录版本，升级前一致性备份，失败不继续业务写入，不做复杂自动降级。

数据目录方案已确认：应用配置指定唯一数据目录，内部可建子目录；不额外建立启动配置或多目录索引隔离。目录变更通过应用配置接口执行。新路径必须为空目录或不存在，自动创建不存在目录，拒绝非空目标，不执行覆盖。迁移需暂停写入、复制校验和功能验证，成功后保存新配置并清理旧应用目录；失败保留可恢复状态。中断恢复和路径及删除边界作为必要的数据保护机制。

密钥方案已确认：用户显式配置，数据目录内明文保存，无环境变量兜底；后端查询只返回掩码与状态，支持可用性测试；不向前端持久化、不进入日志和错误响应，配置变更失效客户端缓存。明文密钥随目录迁移与备份，不能将掩码误视为加密。

问答执行协议已确认：创建异步任务，按标识查询结果，SSE 推送阶段和完成通知，断线不重新生成；Axios 处理普通请求。支持尽力取消，阻止后续阶段及迟到结果覆盖取消状态；重启后中断，不自动重新执行收费调用。问答任务不同于支持检查点恢复的索引任务。

并发与重试已确认：默认一个索引任务和一个问答任务并行，可配置；共享模型限流协调，SQLite 串行写入，等待队列有界。问答模型不自动重试，预处理失败回退，生成或校验失败结束；后台索引保持最多三次尝试。队列容量、供应商配额与具体超时待测试。

清理与备份已确认：问答固定开始时的索引版本，等在途读取结束后幂等清理废弃版本，失败重试不影响新版本；历史引用保存位置和必要证据快照。暂停变更后备份 SQLite、文件与配置版本信息，不纳入 Qdrant 快照；恢复时核查并按需重建索引，提示费用和耗时。

本机部署与访问保护已确认：开发时 Vite 代理接口，发行时 Spring Boot 同源提供前端静态资源和后端接口；仅监听回环地址，校验 Host 和来源，不开放任意跨域；采用 HttpOnly 会话 Cookie 与防跨站请求令牌，不引入账号体系。

代码组织与接口已确认：后端业务包优先、包内分层，跨业务只通过公开接口，问答复用检索，基础设施不反向依赖业务；前端按功能组织，复用后再提取公共内容；普通接口 REST、进度 SSE、统一错误结构与独立传输对象。

构建与发行已确认：Windows x64 和主流 Chrome、Edge；frontend-maven-plugin 固定 Node.js 与 pnpm 并接入根 Maven 验证，前端可独立开发；发行包含 Java 运行时的压缩包与启动脚本，Qdrant 独立部署，不携带个人数据。

技术基线已确认：Java 21、Spring Boot 4.1.x、Spring AI 2.0.2、Maven 3.9.x；嵌入采用 DashScope `text-embedding-v4`、1024 维作为评测基线。已验证 `D:/install/Java/jdk-21.0.13.0.3/bin/java.exe` 可运行。数据访问最终保持 JdbcClient，不采用中途提出的 Spring Data JDBC。
