## 统一解析输出与持久化

解析阶段在事务外执行，输出有序结构单元及来源映射：正文、格式、内容版本标识、解析规则版本、源范围、结构身份、标题路径和续片信息。短事务只负责保存检查点、切片、任务状态和发布前资格核验；远程嵌入及向量写入不在事务内。

统一规范化仅用于解析副本：严格 UTF-8；只删除首个 BOM；将 CRLF 和孤立 CR 统一为 LF；从 1 开始计文本源行并保留末尾空行。原始副本字节、哈希、大小和下载内容始终不变。内部 UTF-16 偏移只用于精确提取，切片长度按 Unicode 码点计量，不切断代理对。

## Markdown 解析与位置规则

采用 CommonMark 0.32.0，启用源位置（SourceSpan）；管道表格显式启用 GFM tables 扩展，版本固定且与前端固定样例核对。解析器不执行原始 HTML、链接、图片或代码，不访问文档提供的网络地址。

- `titlePath` 从外到内，包含当前所属标题；标题块自身包含自身标题。
- `paragraphId` 绑定真实段落或单个列表项；同一结构拆片共享身份；跨独立结构聚合时为 `null`。`structureId` 绑定实际结构容器，续片共享同一身份；跨无共同容器聚合时为 `null`。
- `continuationIndex` 仅表示同一结构的续片，从 0 开始；不适用为 `null`。标题、表头和重叠注入文本计入 2,000 码点硬上限及目标重叠 200；超限按句子、分隔符、最大长度逐级降级，不丢正文。
- 表格行、列从 0 开始，范围两端包含；表头为第 0 行。Markdown 分隔行属于源行范围但不是数据行。无法可靠确定结构时行列为 `null`，不得捏造。

## PDF 全文提取、阅读顺序与资源边界

PDF 使用 PDFBox 3.0.6 的索引专用有界提取器。现有独立 Java 进程、单并发信号量、`-Xmx128m`、解析超时和最大提取码点限制继续作为资源隔离基础；索引提取必须遍历全文，不得在首个非空文字项抛出成功。超时、输出超过上限或内存受限返回 `RESOURCE_LIMIT`；损坏、加密、无法建立可靠结果返回既有解析失败错误，不发布前缀索引。

阅读顺序固定为实现版本，按页生命周期收集文字及页号映射；位置排序只是确定性输入排序手段，不能宣称恢复复杂版面语义。跨页连续段落、句子和表格保持一份结构来源及起止页，页边界不自动作为句末。页眉页脚默认保留，只有显式配置才可移除。

PDF `Location` 至少提供 `pageStart`、`pageEnd`（从 1 开始、两端包含）；不伪造 Markdown 行号。无法可靠识别的标题路径、段落、表格行列和代码字段为空或 `null`。复杂表格无法可靠恢复时只保留页码，行列全部为 `null`。整页无文字、扫描或加密文件按既有不支持规则处理，不增加 OCR。

## 切片、失败与竞态

解析输出先形成结构单元，再由 08 已有切片器消费；结构优先、固定长度、按页策略仍受 2,000 Unicode 码点硬上限和 200 目标重叠约束。每片 `Location` 必填字段均显式写入，不适用为 `null`；文本行和 PDF 页范围均为闭区间。解析规则版本、阅读顺序版本、降级顺序和计量版本记录在内部结果及任务警告中。

失败、取消、删除、内容版本替代或关联失效时不得发布部分索引；迟到结果不得发布。重启从持久化阶段/批次恢复，不重复已完成的收费嵌入。发布事务再次核验任务、目标内容/配置版本、文件和关联有效，再同事务写入生效指针与切换记录；失败保留旧生效版本。

## 原文版本与竞态闭环

两次 latest 加哈希方案需要两次元数据读取、一次完整读取和本地哈希，且无法打开仍保留但已非 latest 的合法历史版本。推荐 09 仅提前已有契约操作 `previewVersionFile`：前端用证据中的 `fileId` 和 `contentVersionId` 直取指定版本；后端查询目标版本元数据、确认可用、校验版本目录和文件标识，再按目标版本返回媒体与安全头。覆盖 latest 不影响读取；清理竞态返回 410，资料/版本不存在返回 404，磁盘异常返回 500。`downloadVersionFile`、历史切换与完整 12 验收继续留在 12。

指定版本读取不能使用当前 `latestVersion` 解释响应。读取保护、路径越界、符号链接校验及 `Cache-Control: no-store`、`X-Content-Type-Options: nosniff`、沙箱 CSP 沿用既有契约。前端不得以 latest 回退冒充历史证据版本。

## 与前端设计的共同约定

已与 `/root/frontend09` 协商：`titlePath` 含当前标题；段落/列表项身份不使用片序号；跨结构片的段落/结构身份为 `null`；表格行列从 0、表头为 0、分隔行不算数据行；PDF 仅在可靠时提供结构字段；所有契约字段显式存在，不适用为 `null`。协调应将这些语义写入契约说明并完成同一摘要双审。
