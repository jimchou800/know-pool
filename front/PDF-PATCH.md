# PDF 预览错误传播补丁

`pdfjs-dist 6.5.438` 的操作流拒绝处理先通知最后一批操作，再拒绝结果承诺。真实超限图片中，通知可能使操作列表与画布渲染提前成功，遗漏图片且不返回资源错误。

`patches/pdfjs-dist@6.5.438.patch` 通过 pnpm 固定应用到标准与兼容入口：先拒绝能力承诺，再用原始错误取消活跃渲染任务，保留既有流关闭及清理。不改文件解析、资源阈值或工作线程。

`test:coverage` 运行真实引擎自检，核对固定超限图片的公开操作列表与画布渲染均拒绝原始原因；真实浏览器另验证两类资源拒绝、正常中文翻页与原字节下载。上游修复并通过同一组回归后移除此补丁。
