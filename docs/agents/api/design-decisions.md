# 接口开发基线技术决策

本记录解释唯一契约 `openapi.yaml` 的技术选择，不替代其字段、路径和约束。所有业务规则依据技术规格最新确认项；没有引入账号、租户、回滚历史索引、永久检索历史或评测管理页面。

## 双方自行确定的传输选择

- 使用 OpenAPI 3.1，文件采用 JSON 语法保存，属于合法 YAML 子集。接口前缀 `/api/v1`；实体、任务与请求标识使用 UUID 字符串；时间为以 `Z` 结尾的 UTC 时间；整数不得超过 JavaScript 安全整数。
- 对象拒绝未知字段，空值与省略分开；局部更新名称说明允许省略保持、说明空串清除。分页默认二十项、最多一百项，游标不透明；会话按最近更新时间倒序，轮次按创建时间正序。
- 会话 Cookie 配合写请求保护头；来源及主机白名单在服务端执行。事件流只提供阶段和终态通知，结果查询为事实来源，重连不创建收费任务。
- 异步创建使用幂等键，同键不同负载拒绝；失败取消后同键仍返回原任务，显式重试须新键。持久任务与运行期检索的映射生命周期分别管理。
- 预览下载首版采用完整文件响应，不承诺范围请求。指定版本副本清理后明确返回不可用，历史引用展示完整实际切片快照。
- 数据集和知识库名称同类唯一；文件按数据集内完整文件名匹配。比较键统一规范化并转小写，展示名保留原值；实例名称允许重复。

## 已解决的交叉领域问题

- 知识库同时返回发布、运行可用和处理状态；按文件返回最新内容、生效内容、生效配置、目标配置与更新失败。切换关系可分页追溯，配置快照可按版本读取。
- 嵌入配置版本可独立选择，每库保存模型身份快照；凭据有指定版本单独更新操作，因此替换密钥不要求重建，后续请求使用更新凭据，在途请求保留原快照。
- 同实例检索以新提交为准；重启只恢复名称、查询和范围。问答首问原子保存会话与任务，失败及取消也保留已检查范围，未校验答案不出现在结果或事件中。
- 通用取消仅限索引、重建、检索和问答；维护与删除清理不能任意取消。删除清理失败通过全局任务列表发现，专用重试仅清理原任务明确归属资源，不复活业务对象。
- 恢复缺失索引建立明确的待重建失败记录，用户通过单文件或全部失败项重试显式启动重嵌入；恢复本身不自动调用收费嵌入服务。
- 运行参数回显实际启动配置，未实测参数不编造验收值；问题预处理、生成和校验调用次数硬上限不能被预算参数放大。共享模型限流与近期完整历史预算明确分开。

## 操作族覆盖

| 已批准任务范围 | 契约操作族 |
| --- | --- |
| 01、24：工程门禁与本机入口 | 会话、运行状态、统一错误；工程门禁本身由工具实现 |
| 02—05：数据集与文件 | 数据集、逐项上传、集中元数据、重命名、版本原文、删除影响 |
| 06：模型设置 | 生成与嵌入配置、密钥三态、历史版本、独立凭据更新、测试 |
| 07—13：知识库与索引 | 空库创建、来源并集、排除、配置快照、任务、预检、切换、发布下线与管理测试 |
| 14—15：知识检索 | 实例、范围、请求、取消、运行期结果与证据 |
| 16—17：知识问答 | 首问、会话、历史、任务、取消、事件与持久引用 |
| 18—20：失败重试与删除 | 独立及批量失败重试、全局任务、清理重试、影响与逻辑删除 |
| 21—22、24：运行数据与恢复 | 资源设置、向量连接、迁移、备份、恢复、故障阶段和残留重试 |
| 23：固定中文评测 | 工具和报告任务，不额外新增评测产品接口 |

## 证据边界

本轮只确定开发契约并静态检查语法、引用、操作标识、路径参数、安全头和代表性正反样例。尚无正式业务实现、自动契约报告生成器、真实接口测试或真实模型调用，不能据此声称实现对齐率百分之百。

最终批准以 `reviews/frontend-baseline.md` 与 `reviews/backend-baseline.md` 对同一文件字节摘要的独立签认为准。任何后续字节变化都须双方重新确认；本记录不能代替签认。
