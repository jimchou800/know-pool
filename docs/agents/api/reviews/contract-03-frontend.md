## 审阅依据与差异

已依据技术与界面任务 03、统一前端规格、现行技术规格、接口协作规范、双方实施设计以及协调确认的五操作完整公共接口范围，逐路径比较原 `1.0.0` 契约与本草案。变更限定为版本号、上传协议说明及最新预览与下载的说明和共享 410 响应声明，没有改写既有结构或新增客户端请求字段。

确认最新文件不存在为 404，元数据明确标记副本不可用为 410 与 `CONTENT_UNAVAILABLE`，仍标记可用却意外读取失败为 500 与 `INTERNAL_ERROR`。前端能区分资源不存在、副本不可用及服务故障，不把历史正文作为最新正文。

确认结构、数量与总请求限额失败为整体失败且零提交；单份超限、不支持内容、非法名称及批内同名组为 200 逐项失败，其他合法项继续。失败项保留原资料与任务。资源限额引用运行参数，没有将工程初值写死为产品承诺；公共客户端保留多文件、三媒体、四种结果与部分失败语义。

确认严格 UTF-8、可选 BOM 与空文件，拒绝非法编码及 NUL；副本、哈希、大小与下载均基于未改写字节。前端展示层安全解码与后端原始字节保存可独立验证。原草案新增中文编码损坏已修复，最终文件中文正常；“零字节”已精确为“空文件（大小为0）”，消除与 NUL 的歧义。
