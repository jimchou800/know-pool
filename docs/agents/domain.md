# 领域文档约定

## 阅读顺序

探索代码或讨论设计前，先阅读根目录 `GLOSSARY.md`，再阅读 `docs/adr/` 中与当前主题有关的架构决策记录。

文件尚不存在时直接继续；由领域建模技能在术语或决策达成共识后创建，无需预先建立空文档。

## 文档布局

本项目采用单一上下文：

- `GLOSSARY.md`：领域术语、定义及应避免的同义词。
- `docs/adr/`：按 `0001-<决策标识>.md` 编号的架构决策记录。

## 使用规则

任务、设计、代码与测试中的领域概念遵循术语表。发现术语缺口时，在领域建模讨论中解决。

提议与现有架构决策冲突时，明确指出记录编号、冲突内容及重新讨论的理由，由用户确认后更新决策。
